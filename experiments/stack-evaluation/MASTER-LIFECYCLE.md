# マスターの起動単位の共有（2026-11-09）

変更前: `cb1ffda`。起動時に最新マスターを読み、同じEditorの利用中は深い読み取り専用値として共有する。所持品・マクロ・装備は再ロードする。起動中の辞書更新は保存時の内容ハッシュで検出し、編集を保持して再起動を案内する。採用設計はD-05・D-17。

## 責務と公開契約

| 担当 | 所有する規則・状態 |
| --- | --- |
| `master_data` | 深い不変値、取得元指紋、診断、辞書の共有。I/O・編集状態へ依存しない |
| `snapshot_loading` | 起動時の生成、マスターのハッシュ確認、キャラクター情報の再取得、必要なアイコンの描画 |
| `Editor` | マスターの寿命。再ロードへ同じ参照を渡す |
| `SnapshotState` / `save_inputs` | キャラクター編集値は独立させ、起動時マスターを共有。可変辞書の従来入力には対象項目のコピーを維持 |
| 保存処理 | 共有辞書で計画を作成・再検証。依存ロック・ハッシュ・バックアップ・復旧を維持 |

マスターを保存計画JSONへ埋め込まない。権限昇格補助プロセスと共有参照のない直接実行APIは従来の再読込検証を使う。再ロードで初めて必要になるアイコンは取得元ハッシュを確認し、ファイル内位置から描画する。辞書を再デコードせず、アイテムレコードは共有する。CLIのJSON出力は読み取り専用Mappingを通常のJSONオブジェクトへ変換し、実行中の所有者を出力しない。
