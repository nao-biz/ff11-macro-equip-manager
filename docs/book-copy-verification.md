# キャラ間ブックコピーの検証

2026-11-10。要件FUT-002、設計D-21。合成データと作業フォルダー内のファイルを使用した。

## 実装範囲

「編集」→「別キャラへブックをコピー…」で元ブック・先キャラ・先ブックを選び、ブック名・全200マクロ・参照装備セットをまとめてコピーする。セット番号は維持する。確認画面には上書き差分、コピー先の別ブックからの参照、コピー先の持ち物による装備参照の判定を表示する。全体を一操作でUndo/Redoできる。

ブック名を編集状態と一括保存へ追加した。名前の16バイトを保持し、マクロ・装備セットと同じ保存トランザクション、バックアップ・復元・管理者ヘルパーの検証を使う。装備参照が一致しない枠は、既存の補正・枠編集後に書き戻す。
