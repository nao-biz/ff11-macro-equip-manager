# Python画面モック

リポジトリ直下で実行する。Windowsの仮想環境は`python`を`.venv/Scripts/python.exe`に置き換える。

| 対象 | 起動 | 合成GUI確認 |
|---|---|---|
| 装備評価 | `python -m prototypes.equipment_review` | `python -m unittest prototypes.test_equipment_review -v` |
| 従来の3タブ構成 | `python -m prototypes.macro_editor` | `python -m prototypes.test_macro_editor` |

構成・操作・配色の判断は [デザインポリシー](../docs/README.md#仕様を調べる)を参照する。本体と同じTkinter、ActionButton、定型文候補・確認ダイアログの共通部品を使用する。

## 装備評価の採用構成（VIEW-005・VIEW-006）

- 左にセット一覧、中央にゲームと同じ4×4枠と部位別候補、右に常時集計。枠の選択で候補を切り替える。ダブルクリックは候補一覧へフォーカスを移す。
- 候補を選ぶと「現在・候補・差分」を再計算し、適用で現在値を更新する。候補解除は無変更。「直前の適用を戻す」で構成を復元する。
- 主要43項目を分類し、残る項目・集計外・計算根拠は「全項目・内訳」で確認する。未取得のある比較は既知分のみを示し、差分を未確定にする。
- 配置・分類・主要項目はD-17・D-18で採用済み。基準1440×900、最小1320×840で、主要項目と候補選択・適用を同時に確認する。
- 数値・装備名は合成データ。長い能力名、負数、小数、割合、条件付き効果、同名のPath違い、未取得を含む。英語原文を本体の正規化・集計処理へ渡す。分類と主要項目も本体と共通。未対応の表記は原文を内訳に残す。実データでの集計検証は未実施。
- メモリ内の16枠の計算と入力・描画はUIスレッドで実行する。ゲーム読込・保存や長時間処理はない。本体へ接続する際はD-15の実行境界に従う。

## 従来モックの確認範囲と制約

- マクロの選択・6行編集・定型文入力、装備枠の候補選択・適用・取消、インベントリの収納・名前検索を試せる。
- SAFE-001に従う合成データと辞書を使用。保存はメモリ上の基準値更新で、終了時に内容が失われる。
- ゲーム保存・補正・装備集計の計算は未接続。集計欄は固定値。
- 入力と描画はUIスレッドで実行する。ファイルI/Oや長時間処理はない。
